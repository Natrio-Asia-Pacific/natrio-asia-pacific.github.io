What the application does

Camera viewing, local analysis and optional review

The camera account owner authorises access to the intended Nest device. Approved operators can then use the private application to view and evaluate its camera features.

01 / CONNECT

View an authorised camera

Google's device permissions allow the application to discover the selected camera and establish live viewing. The owner can revoke that connection.

02 / ANALYSE LOCALLY

Evaluate activity in the browser

Local models analyse displayed frames for people and doorway activity. This continuous analysis does not send those frames to an AI service.

03 / REQUEST A REVIEW

Review selected images with AI

With separate session consent, an operator can send selected images and a question to Google Cloud Vertex AI. Processing may occur outside Australia.

Camera video is available only through the protected application. This information website contains no camera feed, camera images or connection credentials.
